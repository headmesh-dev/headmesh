Headmesh is an open, self-hostable, multi-tenant control layer for private WireGuard meshes. It builds on
[Headscale](https://github.com/juanfont/headscale) and the standard Tailscale clients, and adds what you need to
share machines between people and organisations who don't fully trust each other: isolated workspaces, one-link
onboarding, time-limited grants and sandboxes for AI agents.

:::note[Early development]
Headmesh hasn't had its first release yet. These pages are short on purpose and link to the
[repository](https://github.com/headmesh-dev/headmesh), where the design and the code live. They'll grow as
features ship. [Join the waitlist](/waitlist/) to hear when early access opens.
:::
