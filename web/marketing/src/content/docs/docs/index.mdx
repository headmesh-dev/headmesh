Headmesh is an open, self-hostable control layer for private WireGuard meshes. On top of
[Headscale](https://github.com/juanfont/headscale) and the standard Tailscale clients, it adds what sharing machines
between people who don't fully trust each other needs: isolated workspaces, one-link onboarding, time-limited grants
and sandboxes for AI agents.

:::note[Early development]
The first pre-release, v0.1.0-alpha.1, is for testing only. These pages grow as features ship; the design and the code
are in the [repository](https://github.com/headmesh-dev/headmesh). [Join the waitlist](/waitlist/) to hear when
early access opens.
:::
