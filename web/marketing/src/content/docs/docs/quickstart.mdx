## How joining will work

1. An admin of a workspace creates an **invite** for a device or a teammate. Each invite has a role, a use limit
   and an expiry.
2. The invite comes with a join page and a one-line command for the device, along the lines of:

   ```sh
   npx @headmesh/cli join hmj_…
   ```

3. The CLI enrols the device with a single-use key that expires in minutes, starts the standard Tailscale client
   pointed at your Headmesh network, and names the device after your workspace.
4. The device appears in your workspace, and only the rules and grants you've set decide what it can reach.
