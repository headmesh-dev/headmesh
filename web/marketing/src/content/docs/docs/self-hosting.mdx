---
title: Self-hosting
description: Run Headmesh, Headscale and the cell agent on your own servers.
---

Everything runs on infrastructure you control: the server, the cell agent and Headscale. No closed control server
sits in the loop.

:::caution[Not released yet]
A full guide lands with the first stable release. Until then, the deploy scripts in the repository are the
reference.
:::

## What you'll run

- **headmesh-server**: the API, the sign-in service and background workers, backed by PostgreSQL.
- **Headscale**: the open-source coordination server, one per cell.
- **headmesh-cellagent**: runs beside each Headscale and connects out to the server, so Headscale's API stays
  private.
- A reverse proxy for TLS (the reference deployment uses nginx).

A single small VM can run all of it for a team.

## Where to read more

- [`deploy/`](https://github.com/headmesh-dev/headmesh/tree/main/deploy): the deploy script, nginx templates and the
  server bootstrap.
- [`docs/`](https://github.com/headmesh-dev/headmesh/tree/main/docs): the architecture and decision records.
